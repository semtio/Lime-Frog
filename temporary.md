# SSH Find & Replace Tool — Техническое Задание

## Описание
Инструмент для администратора без навыков программирования. Позволяет находить одинаковый текст во множественных файлах на сервере и заменять его на индивидуальные строки для каждого файла.

---

## Архитектура данных

### Этап 0: Автоматический поиск доменов и файлов

При подключении к серверу система автоматически:
1. Сканирует стандартные директории (/home/, /var/www/, etc.)
2. Находит все домены и их структуры
3. Кеширует информацию о доступных файлах
4. Создаёт индекс `filename → [полные пути]` для каждого домена

**Пример структуры на сервере:**
```
/home/admin/web/billionairesp.in/public_html/header.php
/home/admin/web/billionairesp.in/public_html/footer.php
/home/admin/web/billionairesp.in/public_html/plugins/tinymce/data/content-1.html
/home/user123/www/otherdomain.com/header.php
/home/user123/www/otherdomain.com/index.html
```

### Поле 1: Выбор файлов (вместо ручого ввода путей)
- **Тип:** Dropdown (выпадающий список) + Checkbox для выбора доменов
- **Логика:**
  - Пользователь выбирает тип файла: `header.php`, `index.html`, `content-*.html`
  - Система автоматически находит все файлы с таким именем/паттерном
  - Показывает список доменов где найден этот файл
  - Администратор выбирает, в какие домены применять замену
- **Пример результата:**
  ```
  ✓ billionairesp.in/public_html/header.php
  ✓ otherdomain.com/header.php
  ✓ thirddomain.ru/admin/header.php
  ```
- **Требования:**
  - Поиск по имени файла + regex-паттернам
  - Исключение бэкапов и временных файлов
  - Показ полного пути для предпросмотра

### Поле 2: Текст для поиска
- **Тип:** однострочный текст (input или однострочный textarea)
- **Содержание:** **ВСЕГДА одна строка** — единый поисковый паттерн
- **Пример:** `</title>`
- **Требования:**
  - Поиск точного совпадения во всех файлах
  - Не пусто
  - Видимое текстовое представление для пользователя

### Поле 3: Текст для замены
- **Тип:** многострочный текст (textarea)
- **Содержание:** строки замены, **по одной на файл**
- **Количество строк:** должно совпадать с количеством файлов в Поле 1
- **Пример:**
  ```
  </title> <!-- для header.php
  </title> <!-- для footer.php
  </title> <!-- для file.php
  ```
- **Требования:**
  - N строк = N файлов
  - Соответствие по строкам (строка N → файл N)
  - Валидация совпадения количества

## Алгоритм работы

### Фаза 1: Сканирование сервера (при первом подключении)
```
1. Подключиться к серверу по SSH
2. Определить домашние директории и корневые пути для доменов
   - Ищем: /home/*/web/*, /home/*/www/*, /var/www/*, /usr/local/www/*
3. Для каждого найденного домена:
   - Собрать список файлов .php и .html
   - Создать индекс: тип файла → список абсолютных путей
4. Кешировать результат локально
```

### Фаза 2: Выбор файлов администратором
```
1. Администратор выбирает тип файла (header.php, index.html, etc.)
2. Система показывает все домены, где этот файл найден
3. Администратор отмечает, в какие домены применять изменение
4. Система создаёт список целевых файлов
```

### Фаза 3: Замена текста во всех файлах
```
ДЛЯ КАЖДОГО отмеченного домена:
  1. Прочитать содержимое файла
  2. Найти текст из Поля 2
  3. Если найдено:
       - Создать резервную копию
       - Заменить на свою строку из Поля 3
       - Записать обновлённый файл на сервер
       - Логировать успех
  4. Если не найдено:
       - Логировать ошибку
```

## Технические детали: Умный поиск файлов

### Стратегия поиска доменов (Python backend)
```python
Стандартные префиксы для сканирования:
- /home/*/web/*/public_html/
- /home/*/www/*/public_html/
- /home/*/public_html/
- /var/www/*/public_html/
- /usr/local/www/*/
- $HOME/web/*/public_html/  (для каждого пользователя)

Исключить:
- .backup, .tmp, .bak папки
- node_modules, vendor
```

### Индексирование файлов
```python
# Для каждого найденного домена:
domain_files = {
    "header.php": "/home/admin/web/domain.com/public_html/header.php",
    "footer.php": "/home/admin/web/domain.com/public_html/footer.php",
    "index.html": "/home/admin/web/domain.com/public_html/index.html",
    "content-*.html": [
        "/home/admin/web/domain.com/public_html/plugins/tinymce/data/content-1.html",
        "/home/admin/web/domain.com/public_html/plugins/tinymce/data/content-2.html",
    ]
}

# Глобальный индекс:
all_domains = {
    "domain.com": domain_files,
    "otherdomain.com": domain_files,
    ...
}
```

### Кеширование
- Сохранить индекс в `~/.lime-frog/server_cache_{server_id}.json`
- Время жизни кеша: 1 час
- Кнопка "Пересканировать" для ручного обновления

---

✅ **Обязательно:**
- Ограничение только на .php и .html файлы
- Валидация абсолютных путей (против ../ и обхода директорий)
- Резервная копия файла перед изменением
- Логирование всех операций (что найдено, что заменено, когда)
- Откат при ошибке (восстановление из резервной копии)

🔒 **Протокол:**
- SSH подключение через выбранный сервер из панели
- Запрет на произвольные bash-команды
- Только операции чтения/записи file

## UI/UX

### Блок 1: Выбор файла для редактирования
- **Dropdown:** Выбрать тип файла (header.php, footer.php, index.html, content-*.html)
- **Кнопка:** "Найти файлы" (вызывает сканирование)
- **Список с чекбоксами:** Все найденные домены с путями
  ```
  ✓ billionairesp.in → /home/admin/web/billionairesp.in/public_html/header.php
  ✓ otherdomain.com → /home/user/www/otherdomain.com/header.php
  ☐ thirddomain.ru → /home/admin2/web/thirddomain.ru/header.php
  ```

### Блок 2: Поле поиска
- **Однострочный input:** Текст, который нужно найти во ВСЕХ выбранных файлах
- Пример: `</title>`

### Блок 3: Поле замены
- **Многострочный textarea:** Строки замены, по одной на домен (в том же порядке, что в Блоке 1)
- Автоматическое добавление/удаление строк при выборе доменов

### Кнопки действий
- **"Предпросмотр"** (secondary) — показать что изменится в каждом файле
- **"Применить замену"** (primary) — выполнить замену
- **"Отмена"** (danger) — закрыть форму

### Статусы
- ✅ Успешно: N файлов обновлено (список файлов)
- ❌ Ошибка: указать какой именно файл
- ⚠️ Сканирование: "Поиск файлов на сервере..."
- 🔄 Обновление: "Применяем изменения..."
