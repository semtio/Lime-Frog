# Основная проблема с правами доступа

## Суть проблемы

Сервер настроен так, что:
- Вход по SSH разрешен только пользователю **admin**
- Попытка входа как **root** отклоняется сервером

При этом на сервере есть файлы, которые созданы под root (UID=0):
- `/home/admin/web/1w-lucky-jet.ru/public_html/index.html` (владелец: root)

## Что происходит

1. Мы подключаемся как **admin** (это возможно)
2. Пытаемся изменить права файла root'а через `chmod 777`
3. **Ошибка**: Permission denied — admin не может менять права чужих файлов

## Почему это важно

Инструмент "Замена текста в файлах" нужен для быстрого редактирования сразу нескольких файлов на сервере. Но если файл принадлежит root'у, мы не можем его редактировать как admin.

## Решение

Нужно на сервере выполнить (один раз):
```bash
chown -R admin:admin /home/admin/web/
```

Это сделает пользователя `admin` владельцем всех файлов в директории. После этого:
- Права смогут меняться
- Файлы смогут редактироваться
- Инструмент будет работать полностью

После выполнения этой команды система будет работать как надо.
