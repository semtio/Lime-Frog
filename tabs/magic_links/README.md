# Extract Anchor Text & Extract Alt Image

Две утилиты командной строки для извлечения данных из HTML:

- **`extract_anchor_text.py`** — извлекает текст ссылки (`<a>`) по целевому URL
- **`extract_alt_img.py`** — извлекает атрибут `alt` из изображений внутри ссылок

Обе утилиты поддерживают **многопоточную обработку** для ускорения работы.

## Требования

- Python 3.9+
- Установленные зависимости из `requirements.txt`

## Установка зависимостей

```powershell
pip install -r requirements.txt
```

## Использование

### Extract Anchor Text

Скрипт считывает файл с парами URL, скачивает HTML по первой ссылке и извлекает человекочитаемый текст ссылки, у которой `href` совпадает со второй ссылкой (после канонизации).

```powershell
python extract_anchor_text.py --in input.txt --out result.csv --delay 0.5 --timeout 15 --flow 10
```

### Extract Alt Image

Скрипт извлекает значение атрибута `alt` из тега `<img>`, который находится внутри ссылки `<a href="...">`.

```powershell
python extract_alt_img.py --in input.txt --out result.csv --delay 0.5 --timeout 15 --flow 10
```

## Параметры командной строки

| Параметр | Описание | По умолчанию | Обязательный |
|----------|----------|--------------|--------------|
| `--in` | Путь к входному UTF-8 файлу с парами ссылок | — | ✅ Да |
| `--out` | Путь к результирующему CSV | `out.csv` | Нет |
| `--delay` | Задержка между HTTP-запросами (секунды) | `0.5` | Нет |
| `--timeout` | Таймаут HTTP-запроса (секунды) | `15.0` | Нет |
| `--flow` | **Количество параллельных потоков** | `10` | Нет |
| `--ua` | Переопределение заголовка `User-Agent` | Chrome UA | Нет |

## 🚀 Многопоточность

**Новая функция!** Оба скрипта теперь поддерживают параллельную обработку URL с помощью параметра `--flow`.

### Как это работает:

1. Скрипт создает пул потоков (по умолчанию 10)
2. Каждый поток обрабатывает свою задачу параллельно
3. Результаты записываются в CSV с использованием thread-safe блокировок
4. Задержка `--delay` сохраняется для вежливого скрейпинга

### Примеры:

```powershell
# 10 потоков (по умолчанию)
python extract_anchor_text.py --in input.txt --out result.csv --delay 0.5 --flow 10

# 20 потоков для большей скорости
python extract_anchor_text.py --in input.txt --out result.csv --delay 0.3 --flow 20

# 5 потоков для осторожного парсинга
python extract_alt_img.py --in input.txt --out result.csv --delay 1.0 --flow 5
```

### Ожидаемое ускорение:

- **10 потоков**: ускорение в 5-8 раз
- **20 потоков**: ускорение в 8-15 раз
- Зависит от скорости ответа сайтов и вашего интернет-соединения

## Формат входного файла

Каждая строка содержит две абсолютные ссылки, разделённые пробелом:

```
https://site.com/page1 https://site.com/target-link
https://example.com/home https://example.com/products
```

- Пустые строки игнорируются
- Строки, начинающиеся с `#`, игнорируются (комментарии)

### Пример файла `input.txt`:

```
# Это комментарий
https://example.com https://example.com/more
https://site.com/page https://site.com/link

# Еще одна пара
https://test.org/home https://test.org/about
```

## Формат выходного файла

CSV с колонками:

### Для `extract_anchor_text.py`:
- `first_url` — URL страницы, на которой производится поиск
- `second_url` — целевой URL ссылки
- `anchor_text` — извлеченный текст ссылки
- `status` — статус обработки

### Для `extract_alt_img.py`:
- `first_url` — URL страницы, на которой производится поиск
- `second_url` — целевой URL ссылки
- `image_alt` — извлеченный атрибут alt изображения
- `status` — статус обработки

### Возможные статусы:

| Статус | Описание |
|--------|----------|
| `ok` | Успешно найдено и извлечено |
| `not_found` | Целевая ссылка не найдена на странице |
| `bad_input` | Некорректный формат входных данных |
| `http_error:<code>` | HTTP ошибка (например, `http_error:404`) |
| `timeout` | Превышен таймаут запроса |
| `parse_error` | Ошибка парсинга HTML |

## Примеры использования

### Пример 1: Извлечение анкорного текста

Входной файл `links.txt`:
```
https://example.com https://example.com/more
```

Если на странице `https://example.com` есть ссылка:
```html
<a href="/more">Подробнее о нас</a>
```

Результат в `result.csv`:
```csv
first_url,second_url,anchor_text,status
https://example.com,https://example.com/more,Подробнее о нас,ok
```

### Пример 2: Извлечение alt из изображений

Входной файл `images.txt`:
```
https://example.com https://example.com/products
```

Если на странице есть:
```html
<a href="/products">
  <img src="pic.jpg" alt="Наши товары">
</a>
```

Результат в `result.csv`:
```csv
first_url,second_url,image_alt,status
https://example.com,https://example.com/products,Наши товары,ok
```

## Мониторинг прогресса

Скрипты выводят прогресс в консоль в реальном времени:

```
[1/100] https://example.com -> ok
[2/100] https://site.com -> http_error:404
[3/100] https://test.org -> timeout
...
[100/100] https://last.com -> ok
```

Формат: `[номер/всего] URL -> статус`

## Код возврата

- **`0`** — все запросы обработаны успешно (статус `ok` или `not_found`)
- **`1`** — были ошибки (`http_error:*`, `timeout`, `parse_error`)

Это позволяет использовать скрипты в автоматизированных процессах.

## Особенности канонизации URL

Скрипты используют умную канонизацию URL для сопоставления:

- Приведение схемы и домена к нижнему регистру
- Декодирование и нормализация пути
- Удаление завершающих слэшей (кроме корневого `/`)
- Сортировка параметров запроса
- Учет тега `<base href="...">` на странице

Это позволяет находить ссылки даже если они записаны в разных форматах:
- `/products` найдет `https://site.com/products`
- `HTTPS://SITE.COM/path/` совпадет с `https://site.com/path`

## Рекомендации по производительности

1. **Выбор количества потоков (`--flow`)**:
   - Для быстрых сайтов: 15-20 потоков
   - Для медленных сайтов: 5-10 потоков
   - Для защищенных сайтов: 3-5 потоков

2. **Задержка (`--delay`)**:
   - Без защиты: 0.2-0.5 сек
   - С защитой от парсинга: 1.0-2.0 сек
   - Для вежливого скрейпинга: 2.0-5.0 сек

3. **Баланс скорости и надежности**:
   - Больше потоков = быстрее, но больше нагрузка на сайт
   - Больше задержка = медленнее, но безопаснее

## Устранение неполадок

### Проблема: "Слишком много запросов" (429 ошибка)

**Решение**: Увеличьте `--delay` и уменьшите `--flow`:
```powershell
python extract_anchor_text.py --in input.txt --out result.csv --delay 2.0 --flow 3
```

### Проблема: Timeout ошибки

**Решение**: Увеличьте `--timeout`:
```powershell
python extract_anchor_text.py --in input.txt --out result.csv --timeout 30
```

### Проблема: Скрипт работает медленно

**Решение**: Увеличьте `--flow` и уменьшите `--delay`:
```powershell
python extract_anchor_text.py --in input.txt --out result.csv --delay 0.2 --flow 20
```
